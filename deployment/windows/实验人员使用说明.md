# 异域同行：实验人员使用说明

本文件夹是可独立运行的 Windows x64 实验包，无需安装 Node.js、R 或其他开发软件。请先完整解压，不要直接在压缩包预览窗口中运行。

## 实验前

1. 将主试电脑连接到实验室局域网，或在 Windows“设置 → 网络和 Internet → 移动热点”中开启热点。
2. 双击 `启动实验.cmd`。首次运行若出现 Windows 防火墙提示，只允许“专用网络”，不要开放公用网络。
3. 浏览器会自动打开主试端。建立房间后，用主试端显示的二维码和 WiFi 名称引导被试加入。
4. 先用一台备用手机走完“进入房间—知情同意—签名—开始任务”的简短检查，再正式招募。

## 实验中

- 主试端只在主试电脑上使用；不要把带有管理令牌的地址发送给被试。
- 被试手机必须与主试电脑处在同一局域网。若手机打不开页面，先关闭手机蜂窝数据或“自动切换到移动网络”，并确认热点没有启用客户端隔离。
- 不要移动、重命名或删除本文件夹中的 `data`、`.run` 和 `runtime` 目录。
- 电脑不要休眠；建议连接电源，并关闭系统的自动更新重启。

## 实验结束

1. 在主试端确认所有被试均已结束，并导出当次实验数据。
2. 关闭所有被试页面后，双击 `停止实验.cmd`。
3. 双击 `备份数据.cmd`，把生成的 `backups` 文件夹和主试端导出文件复制到至少一个独立存储位置。

原始数据库位于 `data\experiment.sqlite`。每次重新启动会继续使用同一数据库，不会自动清空既有记录。发行包初始不包含任何被试数据。

## 常见问题

- **启动后浏览器没有打开**：查看同目录的 `连接信息.txt`，复制主试端地址到浏览器。
- **提示端口3000被占用**：先确认是否已经启动过实验；若没有，请关闭占用3000端口的其他程序。
- **二维码能扫但手机打不开**：确认手机与主试电脑在同一WiFi，防火墙仅允许专用网络，并检查路由器或热点是否禁止设备间通信。
- **公网模式**：应用可以填写公网访问地址，但HTTPS、域名和安全隧道必须由技术人员提前配置；不要直接把主试电脑端口暴露到互联网。
