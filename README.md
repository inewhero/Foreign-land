# 异域同行

## 实验人员发行包

在 Windows x64 开发机上运行以下命令，可以执行测试、验证正式序列、构建界面，并生成包含便携 Node 运行时的一键实验包：

```powershell
npm run package:field
```

产物位于 `releases/`，包括可直接解压使用的文件夹、ZIP压缩包和SHA256校验文件。发行包不包含开发数据库、模拟结果、Stan环境或任何既有被试数据；实验人员只需双击“启动实验.cmd”，结束后使用“停止实验.cmd”和“备份数据.cmd”。详细操作说明会随包附带。

一套由主试电脑运行的 jsPsych 群体实验。2–100 名参与者可通过现场局域网或预先配置的公网入口，用手机扫码进入 Room；主试端统一开启区组、监控连接和进度并导出数据。浏览器标题及参与者页面只显示“异域同行”。

## 启动

需要 Node.js 22.5 或更高版本（当前已在 Node 24 上验证）。

```powershell
npm install
npm run build
npm run start
```

启动后终端会显示：

- 被试入口：局域网 IP 与端口；
- 主试入口：仅本机可用、包含控制凭据的 URL；
- 六位 Room 码。

主试也可以直接打开 `http://127.0.0.1:3000/admin`。控制台可切换“局域网/公网”，并显示可点击放大的二维码。局域网模式下先填写现场 Wi‑Fi 名称，放大二维码时会按“先连接指定 Wi‑Fi、再扫码”的顺序提示。波次使用 T0–T8 下拉框、组别使用实验组/对照组下拉框，默认分别为 T0 和实验组；内部版本由服务器自动平衡，主试只填写可选备注。

## 实验结构

- 四个异域地点对应四类经典博弈环境；名称与条件不向参与者揭示。
- 四个地点分别使用苔绿、雾蓝、暖褐、灰紫四种低饱和、近似等亮度的环境背景，帮助参与者区分地点；每位参与者的地点—颜色对应关系由研究编号随机且可复现地排列，因此颜色不会与某类博弈固定绑定。行动按钮、合作/背叛图形和反馈强调色不随地点变化。
- 每个地点有两位同行者，共使用“同行者 A–H”。
- `ctp-v2` 支持短版 96 试次（每位同行者 12 条记录）和长版 192 试次（每位同行者 24 条记录）；长版包含短版核心并增加匹配扩展记录。
- 每个地区代表一种稳定的遭遇环境，并使用与地名一致的守关者称呼，例如“青屿守关者”。每条记录呈现同行者在该地区的一次过往遭遇；随后参与者在同一地区独立经历一次新的同类遭遇。页面明确说明两次不是同一局、积分互不影响，且不要求记忆额外人物身份。
- “合作”始终解释为共享补给，“背叛”始终解释为独占补给；选择按钮、同行者记录和反馈页使用一致的文字与非字母图形。页面不提前呈现收益矩阵，四类环境的差异通过实际结果逐步显现。
- 同行者记录不会决定参与者收益，从而分离社会观察与直接战略互动；记录来自带哈希的固定序列库，不会随被试先前选择改变。
- 同一地区的两位同行者分别使用稳定和易变的证据序列；行动、结果、守关者回应与延迟经过平衡，延迟只用于拟真。
- 每个区组开始前有至少 12 秒、必须主动确认的行前说明；首次遇到每位同行者时另有至少 5 秒说明。
- 预测与正式选择均限制为 6 秒。
- 每个地点结束后有服务器强制的 60 秒休整和全员准备屏障。
- 正式选择按钮在预测、选择两个阶段使用固定尺寸和位置；累计积分以无边框纯文字形式，在观察、判断、选择、等待、结果和超时重试页面固定于同一位置。每轮结果固定呈现 3 秒。
- 全部地点结束后显示服务器保存的最终累计积分，并提示参与者截图保存结束页面。

正式研究的主要表型称为 `SVS`（社会结果价值敏感性），同时估计 `TIMESCALE`、`IMI`、`SELF` 和 `PER`。旧版 `bot_beta`、在线切换概率与逐人自由学习率不再用于 v2。

## 被试端可读性规范

- 中文正文不小于 16px、辅助文字不小于 14px、关键标签不小于 15px；选择按钮文字为 17–20px。
- 正文行高使用 1.7–1.8，标题行高不低于 1.3；不混用宋体、等宽字体或字母式行动符号。
- 主要触控目标高度不小于 48px；手机端两张行动卡固定为 154px，阶段切换时不改变位置。
- 深色实验页的辅助文字提高至约 70% 白色不透明度，避免用低对比度表达必要信息。
- 进度、积分和倒计时保持固定位置；短暂服务器处理不插入新的提示页，减少闪屏和视觉重排。

## 数据与恢复

- 默认数据库：`data/experiment.sqlite`；SQLite 使用 WAL 和逐试次事务。
- 数据分为稳定的 `subjects` 和波次级 `assessment_sessions`；同一研究编号可由主试依次开放 T0–T8，剂量与组别在首次开始后锁定。
- 主试端分别导出 UTF-8 的逐试次 CSV 和过程事件 CSV；实验中控制台不显示选择、预测或得分。
- 过程事件表以客户端事件 ID 幂等写入，记录客户端时间与服务器接收时间、会话序号、轮次/阶段、页面呈现与停留、预测/选择/超时/重试/反馈、签署流程、连接和切后台状态，以及视口、屏幕、全屏和在线状态。短时断线时事件保留在内存队列中，重新连接后补传。
- 加入 Room 后先显示版本化知情同意书，强制阅读至少 15 秒，并要求勾选自愿参加。被试需进入覆盖整个浏览器视口的签名板，用手指或触控笔手写签名；支持时同时请求浏览器全屏。签名图像只保存在主试电脑的同意记录表，不下发到进度面板。
- 研究编号与本机恢复令牌绑定，避免另一台设备冒用；正式开始后波次和组别锁定，备注仍可由主试追加。
- 手机只接收自身的最小状态快照，不接收房间名单、研究编号、波次、组别、备注或内部版本。
- 服务器在运行中意外重启时会进入暂停状态，须由主试检查后恢复。

## 单被试控制

主试可在某一参与者行内展开“单被试控制”，单独执行：

- 跳转到第 1–4 段、该段任一同行者及当前剂量允许的下一轮；跳转后的会话自动标记为方案偏离；
- 强制开始该参与者，不改变同 Room 中其他人的状态；
- 强制结束全部流程；
- 强制删除其参与者记录、同意记录、全部试次和过程事件。

跳转和强制操作均写入审计日志。强制结束会立即中止该手机正在运行的 jsPsych 页面；删除必须再次输入完全一致的研究编号，且不可恢复。

## 局域网与公网

本机检测到 Realtek 8822BE 802.11ac 网卡和 Microsoft Wi-Fi Direct 虚拟适配器，具备开启 Windows“设置 → 网络和 Internet → 移动热点”的条件。小规模预试可用本机热点；20–100 人正式场次建议使用独立双频路由器/AP，并让主试电脑通过网线接入。首次启动时还需允许 Windows 防火墙放行 Node.js 的“专用网络”访问。

公网模式只负责把被试二维码切换到填写的公网基址，不会自动部署服务器或创建隧道。请先通过反向代理、VPN/隧道或正式部署，让该地址能够访问本服务，优先使用 HTTPS，并在切换前用非现场网络完成整套连通与断线恢复测试。也可在首次创建数据库前通过 `ACCESS_MODE`、`WIFI_NAME` 和 `PUBLIC_BASE_URL` 环境变量给出默认值；之后在主试控制台保存的设置会写入 Room。

## 校验

```powershell
npm test
npm run build
```

自动测试覆盖四类博弈符号、A–H 条件分配、β×延迟正交化、延迟边界、地区—守关者映射、参与者页面盲法、联机模式持久化和细粒度事件表。正式收数前仍必须做参数生成—恢复模拟和 2、20、100 客户端压力演练。

旧版 CSV 仍可运行探索性个体估计：

```powershell
npm run analyze -- .\expedition-123456.csv
```

检测到 `ctp-v2` 时旧分析器会拒绝运行。正式 v2 流程见 [analysis/README.md](analysis/README.md)，使用固定基函数和 CmdStanPy 层级模型。

## 伦理提示

参与者页面不声称同行者是真人，也不出现“电脑伙伴”。知情同意可描述为“由实验系统安排的同行记录”。若记录是脚本生成，完整研究结束时必须去蔽说明；若基线后紧接干预，可把去蔽放在整个研究的最终终点，避免污染后续测量。
