# ctp-v2 社会学习计算表型说明

## 测量目标

原论文中的 β 是收益差驱动策略切换的确定性，不能直接等同于被试的社会学习敏感性。`ctp-v2` 把个体选择拆为五个可区分的计算表型：

1. `SVS`：社会结果价值对选择的影响；主要表型。
2. `TIMESCALE`：近期社会证据相对长期证据的权重。
3. `IMI`：不依赖结果的即时行动复制。
4. `SELF`：个人结果经验对选择的影响。
5. `PER`：重复上一次选择的倾向。

同行者预测准确率、Brier 分数和随轮次更新斜率只作为注意与同行模型追踪指标，不替代 `SVS`。

## 固定测量设计

- `short96`：4 地区 × 2 位同行者 × 12 试次。
- `long192`：4 地区 × 2 位同行者 × 24 试次；包含 short96 的核心模板并增加匹配扩展试次。
- 每位同行者有 4 个一致、4 个冲突和 4 个中性证据试次；长版各为 8 个。
- 每个短版含 24 个跨波次锚定位置，即每位同行者 3 个。
- 同一地区的两位同行者分别使用稳定和易变序列；边际行动、守关者行动和证据类型严格平衡。
- 社会价值、当前同行行动、地区和序位在验收序列中绝对相关小于 0.10，标准化设计矩阵最大 VIF 小于 2。
- 所有同行者记录、两个守关者行动与延迟由版本化序列模板确定，不读取被试此前选择。被试选择只影响自己的积分与个人经验基函数。

序列库使用固定更新率 `0.50` 和 `0.15` 构造短、长社会证据，再对即时行动、地区、稳定性和序位做预注册正交化。每一会话保存 `protocol_version`、`sequence_id`、哈希、模板 ID 和全部基函数，因此可以完整复现。

## 纵向模型

```text
logit P(合作) = 个体偏好 + 地区效应
               + SVS(i,w) × 社会价值平均证据
               + TIMESCALE(i) × 社会短期−长期证据
               + IMI(i) × 当前同行者行动
               + SELF(i,w) × 个人经验
               + PER(i) × 上一次选择
               + 地区/稳定性调节

SVS(i,w) = 稳定特质(i) + 组别×波次 + 波次状态(i,w)
```

不再逐人搜索自由学习率。T0–T1 预试使用会话状态偏离；正式 T0–T8 使用正则化 AR(1) 状态。只有四种地区方向一致且通过预注册等价筛查时才报告总体 `SVS`，否则报告四地区向量。

正式分析位于 `analysis/`，使用 Python 3.12、CmdStanPy 和锁定依赖。Stan 先验为标准化斜率 `Normal(0,0.5)`、个体标准差 `half-Normal(0,0.5)`、相关矩阵 `LKJ(2)`。拟合必须满足 `R-hat < 1.01`、bulk ESS ≥ 400 且无 divergence。

## 双剂量预试

- 受试者按人区组随机到 short96 或 long192，剂量在 T0 开始后锁定。
- 7±2 天后用相同剂量的平行版本完成 T1，不施加干预。
- 每剂量累计 20、30、40 人检查；20/30 人节点只做完成率、时长、缺失和模型失配质控，不按疗效显著性停止。
- short96 的最终采用条件：完成率 ≥85%、超时率 ≤10%、SVS 后验不确定性不超过长版的 1.15 倍，测试—重测稳定性与长版相差不超过 0.10。
- 若 long192 稳定性仍低于 0.60或不能分离模仿/个人强化，则重做序列，不继续堆叠试次。

`0.3 × T0 SVS 标准差` 暂作最小相关变化阈值；建立外部临床锚定前不得称为临床显著变化。LPA/LTA、策略剖面和 DDM 均不是主要分析。
